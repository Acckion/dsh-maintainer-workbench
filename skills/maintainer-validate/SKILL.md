# maintainer-validate

Validate the supplied change at the recorded SHA and patch. Read repository instructions, run relevant checks under host permissions. Record environment and exact commands, failures and unavailable checks. Do not fix source, commit or publish.

Use the supplied stage schema. Read handoff evidence and maintainer feedback before repeating investigation. Preserve source references and describe coverage. Never publish, commit, push or merge.
