# 0.3.0 事项面板

基线：09a7c49（0.2.3）；回滚标签：ui-before-item-panels-20261009。

Overview、Plan、Work、Review 与 Summary、Activity、Diff 共用一行导航。传统内容居右，窄屏改为两个选择器。移除 Assistant 的混合结果页面和详情内的第二层 Change 页签。PR 的提交和检查放在 Summary 的按需展开区。

## 持久化与权限

`item_drafts` 独立 SQLite 表以完整事项 ID 为键。局部字段更新在事务中合并，客户端对同一事项的写入串行化。计划草稿不写入 Issue.plan；正式确认仍走既有 /issue-plan，服务端拒绝运行中任务的计划变更。所有草稿 API 复用本地来源检查与请求大小限制。

发布评论读取本机回复草稿，未编辑时兼容既有 Agent 回复。预览指纹包含回复文本；提交和每次外部写入前重新核对文本、审批、事项、仓库和补丁。取消预览保留草稿。标签、审查、PR 交付继续走已有保护和去重路径。

## 已验证

- SQLite 重启恢复、字段合并、不同事项隔离；保存草稿不改变确认计划和任务队列。
- 正式计划确认的运行中保护；修改回复使旧发布预览失效；最终读请求期间改变回复不会发送 POST。
- 本机 Chromium 1440px / 390px：计划草稿刷新恢复、目标确认并派发、追问与回复同步、审查发现批量处置、历史发现复核、讨论串预览确认、原始工具日志。
- 原始 Summary/Activity/Diff 浏览不创建 Agent 任务；回复持久保存；Review 位置跳转 Diff 并返回。
- 桌面与窄屏跨仓库派发和审核竞态、返回来源列表、焦点与滚动恢复、慢轮询回归。

本轮不验证真实模型质量，不进行真实远端写入。浏览器夹具仅在测试脚本中，不随插件分发；截图保留在本机临时验证目录。
