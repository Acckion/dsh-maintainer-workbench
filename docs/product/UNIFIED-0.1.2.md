## 合并边界

- 仓库整理事项沿用最新发布预览核验，但检查真实分支，不访问合成 Issue #0。没有唯一 GitHub 远端时仅本地处理或导出。
- 本地无远端的实施、验证、审查仍可交接；远端发布不绕过登录或版本核验。
- 没有修改需要的文档检查仍可成功结束；有补丁时进入既有验证与审查。
- 其他 profile 或旧开发环境的 analysis/worktrees 目录在有工作台数据库标记时排除。失联的空自动发现条目不展示，数据库及历史不删除；重新出现可恢复。
- 保留 Codex/技能借鉴声明与第三方完整许可证；Markdown 浏览相关依赖现纳入运行时清单，共 79 个包。
