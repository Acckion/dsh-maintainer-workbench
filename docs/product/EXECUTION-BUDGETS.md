# Execution budgets and partial results

Tool exploration, per-request output tokens, report formatting, and the task deadline are separate limits. None is a monetary spending cap. Harness still supplies the configured model, Agent preset, permissions and credentials.

`toolCallLimit: 0` selects an automatic exploration allowance: a single scoped file uses 80 requests, a directory or multiple paths 120, and an entire-repository audit 180. Other stages use 80–180 depending on their work. A global override of 10–1000 is available in advanced execution settings and persists through the existing settings API. Old settings default to automatic mode.

A warning is emitted before the allowance is exhausted or searches dominate. Four identical calls stop exploration. Varied directory searches also stop when they substantially outnumber reads. Successful edits clear exact-repeat history, but never renew the overall task allowance. Scope guidance favors direct dependencies and explicit uncertainty over repeated searches to prove absence. Scoped audits omit the broad repository profile, unrelated issues, and discussion payload.

After an exploration stop, guards reject additional reads, searches, commands, edits and subagents while preserving the report tool. At most two further model requests may organize the existing evidence, with at most one explicit closing turn. Report submission does not consume exploration allowance or get counted twice by host guards. If the report cannot be produced, the host saves a deterministic incomplete artifact from actual execution records. Context-capacity stops do not attempt another request with the same oversized input. Deadlines and cancellation never launch another model request; only already recorded evidence is retained.

A partial artifact never makes a task complete. The task remains failed or cancelled, review remains incomplete, validation cannot claim unobserved passing tests, patches and execution logs remain available, and automatic implementation/validation/review successors do not start. Partial repository scans retain actually read paths and valid findings, but cannot resolve prior findings or enter the completed-result cache. A completed queue entry with incomplete coverage is also excluded from reuse. Completed scoped results remain current across unrelated commits when their scope and explicit evidence dependencies are unchanged. Recovery explicitly starts a new current-scope audit. No task receives broader permissions from a budget setting.

Tests cover every tool-using stage, soft/hard limits, changing glob patterns, report exemptions, the two-request closing bound, malformed reports, settings persistence/rejection, deadlines, cancellation, partial audit coverage and preservation of a real implementation patch without successor tasks. Live provider success and cost require a separately authorized model run; mock and browser tests make no model calls.
